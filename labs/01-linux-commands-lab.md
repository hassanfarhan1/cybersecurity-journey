# Lab 01 - Linux Navigation

## Objective

Understand the Linux file system and basic navigation commands.

---

## Commands Used

```bash
pwd
cd /
ls
cd ~
cd /var/log
```

---

## What I Learned

- `pwd` shows the current working directory.
- `cd /` moves to the root directory.
- `ls` lists files and directories.
- `cd ~` returns to my home directory.
- `/var/log` stores important system logs.

---

## Observation

This lab helped me understand how Linux organizes its files and why `/var/log` is important for SOC Analysts when investigating security events.
