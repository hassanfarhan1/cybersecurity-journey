# Lab 05 - Linux Users, Groups & sudo

## Objective

Identify the currently active user on the system.

---

## Environment

- Operating System: Kali Linux
- User: hassan

---

## Commands Executed

```bash
whoami
```

---

## Expected Output

```text
hassan
```

---

## Skills Gained

- Understanding the Linux multi-user model
- Identifying the current user with `whoami`
- Reviewing numeric `chmod` values (7, 6, 5, 4, 0)

---

## Conclusion

This lab confirmed the currently active user account and reinforced the connection between users, groups, and file permissions. Understanding who a user is - and what privileges they hold - is the next step after understanding what permissions control.
